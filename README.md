# 拾光手札

SillyTavern 前端扩展，版本 0.3.1。把喜欢的聊天正文收进干花拼贴风的笔记本。

## 0.3.1 更新

- 消息菜单中的收藏入口改为线条书签图标，移除 emoji、文字和胶囊底框，使用酒馆原生 `mes_button` 样式跟随主题。
- 悬停显示“收藏到拾光手札”，支持键盘 Enter / 空格操作。

## 0.3.0 更新

- 改名「拾光手札」。沿用原插件目录和存储标识，原有笔记无需迁移。
- 恢复外层面板的奶油色背景，只让纸页上的正文、标题、来源区域透明；保留纸张贴图。
- 隐藏目录、正文及封面容器的滚动条，仍可触摸、滚轮和键盘滚动。
- HTML 代码块自动以独立小剧场显示，保留其中的 CSS、文档背景和排版。小剧场在隔离的 iframe 中展示，不执行 JavaScript；内部滚动条隐藏。外部图片仍需要能访问对应图床。
- 插件按钮和输入框样式不再覆盖正文内的小剧场控件。
- 默认进入阅读模式，通过酒馆的 `messageFormatting` 接口使用当前启用的显示正则、Markdown 和 HTML 排版。点“编辑原文”修改，点“阅读排版”预览；保存后自动回到阅读模式。
- 原文与显示效果分开，保存、导出都保留原文。无需迁移旧版笔记。
- 更新前建议导出备份。用新版文件覆盖原插件文件夹，然后刷新酒馆；不要清除网站数据或重置扩展设置。

### 正则的适用范围

整条消息收藏会记录发言人和消息类型；使用酒馆当前启用的显示正则，包括当前角色、预设允许使用的规则。查看其他角色的收藏时，请打开对应角色和预设。旧版笔记缺少消息类型，默认按当前角色的 AI 正文显示。

能够确认仍是原聊天中的同一消息时，会使用原消息位置；否则按独立正文渲染。独立正文和首条消息没有聊天深度，因此带最小/最大深度条件的规则可能与原聊天不同。不会为渲染笔记切换角色或改写原聊天。

选段来自已经显示过的文字，为避免重复替换，保持可见纯文本；需要完整正则美化或 HTML 小剧场时请收藏整条消息。独立预览没有酒馆接口，仍显示纯文本。已支持 HTML 代码块内的静态 HTML/CSS 小剧场；依赖 JavaScript 或其他插件聊天事件的交互不执行。

接口依据：https://github.com/SillyTavern/SillyTavern/blob/release/public/script.js

## 安装

1. 解压 `tasty-notebook.zip`，得到 `tasty-notebook` 文件夹。
2. 将整个文件夹放到 SillyTavern 的 `data/<你的用户目录>/extensions/` 内。例如默认用户通常使用 `data/default-user/extensions/tasty-notebook/`。确认 `manifest.json` 就在 `tasty-notebook` 这一层，没有重复套一层文件夹。
3. 刷新酒馆页面，在扩展管理中确认“拾光手札”已启用。
4. 页面右下方会出现“📖 拾光手札”。每条消息的操作区会出现线条书签图标，悬停提示“收藏到拾光手札”；部分主题需要先展开消息的更多操作。

也可以把本文件夹内的内容放在 Git 仓库根目录，然后使用酒馆的“安装扩展”填写该仓库地址。当前交付的是本地压缩包，尚未发布为可直接填写的 GitHub 安装地址。

官方扩展说明：https://docs.sillytavern.app/for-contributors/writing-extensions/

## 使用

- 点击消息上的“收藏”，将原始消息正文复制到笔记编辑器；修改标题或正文后点击“保存笔记”。
- 先选中同一条消息内的文字，再点击该消息的“收藏”，只收录选段。手机或主题如果清除了选择范围，可先收藏整条消息，再在笔记里修剪。
- 整条收藏保留原始文本，包括原消息内已有的 Markdown 或 HTML 字符；阅读时由酒馆统一进行正则、Markdown 和 HTML 安全处理。编辑模式显示原文；选段收藏使用选择到的可见文字。
- 左侧目录支持搜索标题、正文、来源；上一篇、下一篇按收藏顺序切换，不会把长文章切成多页。长正文在纸页里滚动阅读。
- 可切换 11 种内页；封面、目录以及内页 1、5、6、7、11 已随包附带。内页 2、3、4、8、9、10 使用提供的 jsDelivr 地址，无法加载时显示内页 1。
- 新笔记默认轮换使用 1、11、7，更适合正文摘抄。5、6 原图包含待办或星期标签，可自行选择。
- 支持 Ctrl/Cmd + S 保存；有未保存修改时关闭或切换会提醒。
- 删除笔记不会修改原聊天。收藏也不会修改聊天、提示词或角色卡。

## 保存与备份

正文存在当前浏览器、当前酒馆地址的 IndexedDB 中，以酒馆设置内保存的笔记本标识区分。**不会自动同步到手机、其他浏览器或服务器。** 清除网站数据会清除本地笔记；更换酒馆域名、端口、账号或重置扩展设置后，也可能无法访问原来的本地笔记本。

请定期点击“导出备份”，得到 JSON 文件。换设备后用“导入备份”恢复。导入合并现有笔记，不覆盖；标题、正文、来源完全相同的条目会跳过。导出只包含已经保存的笔记。备份包含正文，请自行保存。

## 独立预览

本文件夹包含 `preview.html`，与酒馆使用同一套笔记界面，但保存到单独的预览笔记本。

在本文件夹运行一个本地 HTTP 静态服务器，然后访问 `preview.html`。例如已装 Python 时运行 `python -m http.server 8765`，打开 `http://localhost:8765/preview.html`。不建议双击 HTML：浏览器通常限制 file:// 下的 JavaScript 模块。
