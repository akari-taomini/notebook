# 好吃的正文 · 收藏笔记

SillyTavern 前端扩展，版本 0.1.0。把喜欢的聊天正文收进干花拼贴风的笔记本。

## 安装

1. 解压 `tasty-notebook.zip`，得到 `tasty-notebook` 文件夹。
2. 将整个文件夹放到 SillyTavern 的 `data/<你的用户目录>/extensions/` 内。例如默认用户通常使用 `data/default-user/extensions/tasty-notebook/`。确认 `manifest.json` 就在 `tasty-notebook` 这一层，没有重复套一层文件夹。
3. 刷新酒馆页面，在扩展管理中确认“好吃的正文 · 收藏笔记”已启用。
4. 页面右下方会出现“📖 正文笔记”。每条消息的操作区会出现“📑 收藏”，部分主题需要先展开消息的更多操作。

也可以把本文件夹内的内容放在 Git 仓库根目录，然后使用酒馆的“安装扩展”填写该仓库地址。当前交付的是本地压缩包，尚未发布为可直接填写的 GitHub 安装地址。

官方扩展说明：https://docs.sillytavern.app/for-contributors/writing-extensions/

## 使用

- 点击消息上的“收藏”，将原始消息正文复制到笔记编辑器；修改标题或正文后点击“保存笔记”。
- 先选中同一条消息内的文字，再点击该消息的“收藏”，只收录选段。手机或主题如果清除了选择范围，可先收藏整条消息，再在笔记里修剪。
- 整条收藏保留原始文本，包括原消息内已有的 Markdown 或 HTML 字符；选段收藏使用选择到的可见文字。笔记以纯文本显示，不执行其中的 HTML。
- 左侧目录支持搜索标题、正文、来源；上一篇、下一篇按收藏顺序切换，不会把长文章切成多页。长正文在纸页里滚动阅读。
- 可切换 11 种内页；封面、目录以及内页 1、5、6、7、11 已随包附带。内页 2、3、4、8、9、10 使用提供的 jsDelivr 地址，无法加载时显示内页 1。
- 新笔记默认轮换使用 1、11、7，更适合正文摘抄。5、6 原图包含待办或星期标签，可自行选择。
- 支持 Ctrl/Cmd + S 保存；有未保存修改时关闭或切换会提醒。
- 删除笔记不会修改原聊天。收藏也不会修改聊天、提示词或角色卡。

## 保存与备份

正文存在当前浏览器、当前酒馆地址的 IndexedDB 中，以酒馆设置内保存的笔记本标识区分。**不会自动同步到手机、其他浏览器或服务器。** 清除网站数据会清除本地笔记；更换酒馆域名、端口、账号或重置扩展设置后，也可能无法访问原来的本地笔记本。

请定期点击“导出备份”，得到 JSON 文件。换设备后用“导入备份”恢复。导入合并现有笔记，不覆盖；标题、正文、来源完全相同的条目会跳过。导出只包含已经保存的笔记。备份包含正文，请自行保存。

## 独立预览

本文件夹包含 `preview.html`，与酒馆使用同一套笔记界面，但保存到单独的预览笔记本。

在本文件夹运行一个本地 HTTP 静态服务器，然后访问 `preview.html`。例如已装 Python 时运行 `python -m http.server 8765`，打开 `http://localhost:8765/preview.html`。不建议双击 HTML：浏览器通常限制 file:// 下的 JavaScript 模块。
